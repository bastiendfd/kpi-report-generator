# Security Policy

## Supported versions

This portfolio project is maintained on a best-effort basis. Security fixes, if any, are applied to the latest version on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead, use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately through GitHub. Include a clear description, reproduction steps, and potential impact.

This tool processes local CSV files only and does not require credentials, network services, or third-party APIs. Do not include secrets or sensitive data in sample files, issue reports, or pull requests.
